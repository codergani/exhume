# Exhume: product steering

Exhume takes a public GitHub repo URL that looks abandoned and returns an autopsy
(why it died) and a resurrection plan (ordered steps to revive it), presented in a
haunted terminal UI.

- Audience: developers who find a useful but abandoned repo and want to know if it is worth saving.
- Category: Kiroween "Resurrection" (reviving obsolete code and tech).
- Tone of all copy: dry, terse, spooky. Never jokey. Errors are in-theme but always say what to do next.
- Non-goals (do NOT build): auto-opening PRs, cloning repos, user accounts, a custom backend, payments.
- Demo rule: every feature must be visible in a 90-second video. If it cannot be shown, do not build it.
